# 3D-demo-sites
Demo 3D websites for local businesses, built with AI and hosted free on GitHub Pages. Every business in these demos is fictional.

| Demo | Folder | What it is |
| --- | --- | --- |
| Ember & Oak Coffee v2 | [`cafe-demo-v2/`](cafe-demo-v2/) | The cinematic, multi-page version: 3D hero, 38-item menu with pick-up ordering, shop, events, gift cards, journal, search and more. Has a build script, data files, tests and a client checklist. |
| Brass & Blade Barbershop | [`barber-demo/`](barber-demo/) | A fictional barbershop: spinning 3D barber pole hero, 24 services with online booking, crew, grooming shop, memberships, journal and more. Same build script and tests as the café v2. |
| Iron & Ember Athletic Club | [`gym-demo/`](gym-demo/) | A fictional gym: spinning 3D barbell hero, 7-day free trial, class timetable, coaches, memberships and a visit form. Same build script and tests as the barber demo. |
| Waverley Plumbing & Gas | [`plumber-demo/`](plumber-demo/) | A fictional family plumber: phone-first light theme, 24/7 emergency call button, suburb checker, price guide, before/after slider, reviews, team and a quote form. Same build script, photo pipeline and tests as the gym demo. |
| Torque & Co. (unofficial concept) | [`parts-store-demo/`](parts-store-demo/) | Home page only: fictional auto parts retailer with a rego/make/model car finder, a "fits your car" bar, shop-by-job drawers, an oil finder and a phone-first layout. Plain HTML/CSS/JS. |
| Maison Lune salon | [`salon-demo/`](salon-demo/) | A fictional hair and beauty salon: ivory, cocoa and clay palette, serif headings, service prices, a front-end booking widget, stylists, before/after, gallery lightbox and gift vouchers. Same build script, photo pipeline and tests as the plumber demo. |
| Ember & Oak Coffee v1 | [`cafe-demo/`](cafe-demo/) | The original warm, single-page version, kept as it was. |

Once GitHub Pages is on, the front page lists the demos: `https://<user>.github.io/3D-demo-sites/`.
