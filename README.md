# 3D-demo-sites

Websites for KB Ventures and its businesses, published with GitHub Pages:

- `black-crest-site/`: KB Web Designs, premium sites for local businesses. The site's home page is the front page of this repo.
- `kbventures-site/`: KB Ventures, with the AceGuides study guide shop.
- `barber-demo/`, `cafe-demo-v2/`, `gym-demo/`, `plumber-demo/`, `salon-demo/`, `parts-store-demo/`: concept sites for made-up local businesses, shown in KB Web Designs's work. Every business in them is fictional.

The house style for every site is in `CLAUDE.md`.
